# FrankyLian_Portfolio

Static engineering portfolio for Franky Lian (Mechanical Engineering, The Ohio State University).

## Files

- `index.html`: all content (about, experience, projects, contact)
- `styles.css`: layout and light/dark theme
- `assets/img/headshot.jpg`: portrait

## Preview locally

    python3 -m http.server 8000

Then open http://localhost:8000.

## Deploy

Enable GitHub Pages on the `main` branch (root folder). No build step is needed.
